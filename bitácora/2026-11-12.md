### 2. Implementación de Actualización Automática en Producción (CI/CD GitHub Actions → cPanel)
- **Workflow de Frontend (`Frontend/.github/workflows/deploy-cpanel.yml`):**
  - Se configuró ejecución automática en cada `push` a `main` (con cola `concurrency` para evitar despliegues simultáneos): instala dependencias en Node.js 24, ejecuta validación integral con Vite+ (`npm run check`), compila el bundle (`npm run build`) y sincroniza `./dist/` hacia la raíz del dominio en cPanel mediante `SamKirkland/FTP-Deploy-Action@v4.3.5`, protegiendo `.htaccess`, `.well-known`, `cgi-bin` y `/apietronic`.
- **Workflow de Backend (`Backend/.github/workflows/deploy-cpanel.yml`):**
  - Se creó el pipeline de integración y despliegue continuo que valida la sintaxis de todos los módulos (`.js`, `.mjs`, `.cjs`) con `node --check`, empaqueta únicamente los archivos de código en `_deploy_pkg/`, genera `tmp/restart.txt` con el hash del commit y marca de tiempo UTC para provocar el **reinicio automático en caliente de Phusion Passenger** en cPanel, y despliega vía FTPS excluyendo `.env`, `.htaccess`, `node_modules` y `data` en aislamiento total respecto a otros dominios del servidor.
